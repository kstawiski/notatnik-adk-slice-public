How to evaluate this demo

Use the source documents as ground truth. The default case has two original synthetic files that disagree on rectal-cancer stage. The agent should expose that conflict, not invent or silently choose a stage.

  1. Read sourcesOriginal synthetic files are visible before the run.
  2. Know the riskWeak drafts can hide gaps or contradictions.
  3. Run ADK loopDocumentation drafts, QC audits, and rewrites.
  4. Check outputLook for discrepancy, trace, and scrub PASS.
What to check before running

In the source pane, compare the MRI and MDT files. For the default case, MRI records cT2 N0 while the MDT note records cT3 N1.
